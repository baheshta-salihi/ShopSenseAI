# ShopSenseAI

### AI-Powered E-Commerce Platform for Women Entrepreneurs in Afghanistan

ShopSenseAI is a web-based e-commerce platform designed to support women entrepreneurs in Afghanistan. It aims to help customers discover, search, compare, and select products more easily through smart product recommendations.

## Project Overview

The project focuses on creating a user-friendly online shopping experience while providing useful tools for product discovery and comparison.

## Key Features

- Product browsing and search
- Product category filtering
- Price filtering and sorting
- Product comparison
- Smart product recommendations
- Backend API using FastAPI
- Responsive web interface

## Technologies Used

| Technology | Purpose |
|---|---|
| Python | Backend development |
| FastAPI | REST API |
| HTML | Web page structure |

## Installation and Setup

1. Clone the repository:

```bash
git clone https://github.com/baheshta-salihi/ShopSenseAI.git
```

2. Open the project directory:

```bash
cd ShopSenseAI
```

3. Install the dependencies:

```bash
pip install "fastapi[standard]"
```

4. Run the application:

```bash
uvicorn main:app --reload
```

5. Open the application in your browser:

```text
http://127.0.0.1:8000/
```

API documentation:

```text
http://127.0.0.1:8000/docs
```
